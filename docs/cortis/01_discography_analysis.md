## 1. EP1 — COLOR OUTSIDE THE LINES (2025-09-08)

트랙: GO!(2:50) / What You Want(3:14, 타이틀) / FaSHioN(2:54) / JoyRide(2:37) / Lullaby(2:44) / WYW feat. Teezo Touchdown(디지털)
프로듀서: Supreme Boi · Hiss Noise · Hitman Bang

- **GO!** — Lo-fi 트랩+팝힙합. 808·하이햇롤. 도착 선언/야망. 브래깅·청춘 에너지, 직구. 영어 위주. EP 오프닝 선언문.
- **What You Want** ⭐ — **60s 사이키델릭 록 기타 + 붐뱁**. 드럼 전면, 악기는 sparse하게 빠져 보컬 부각. 청춘의 꿈 포착, 직접 화법. 영어 주도+한국어 간헐. Chant hook 지배. **CORTIS 사운드 원형.**
- **FaSHioN** — 트랩+서던힙합. GenZ 환경의식·윤리적 패션. 동묘/홍대 등 서울 지명 삽입. 한·영 혼용(EP1 최고 한국어 비율). 앤섬.
- **JoyRide** — 멜로딕 팝(가장 컨벤셔널). 앨범 제작기 고통(고립·탈진) 내성적 회고. 감정 전환점. 영어 주도.
- **Lullaby** — 미니멀 발라드+재즈 시퀀스. 퍼커션 거의 없음. 데뷔 여정 회고·철학적. "소음으로 시작해 침묵으로 끝" 아치 완성.

## 2. EP2 — GREENGREEN (2026-05-04)

트랙: TNT(2:02) / REDRED(2:43, 타이틀) / ACAI(2:53) / YOUNGCREATORCREW(2:56) / Wassup(3:04) / Blue Lips(2:21)
프로듀서: Hiss Noise · Supreme Boi · Thom Bridges · Slush Puppy · Zach Fogarty · Hitman Bang · 멤버(Seonghyeon, Martin 등)

- **TNT** — 트랩 808 + 거친 기타. 수면부족·스튜디오 좌절을 정체성으로. 2:02 압축. 카오틱. 한·영.
- **REDRED** ⭐ — 2000s 일렉트로클래시+인디힙합 = **"Cracked Pop"**. 디스토션 신스·루프·금속 텍스처. Red flag vs Green flag, 남 시선에 자기 잃기 거부. 일부러 unpolished. 한·영.
- **ACAI** — 힙합 계열. 미국 세션 중 아사이볼 영감 → 진정성. 일상 디테일 소재주의. 한·영.
- **YOUNGCREATORCREW** — 프리스타일 랩 기반(데뷔 당일 실제 프리스타일). 그룹 정체성 선언. 내부농담·언필터드·유머. 한·영.
- **Wassup** — 미드템포. 그룹 여행·이동·피로·일상. 회고·그라운디드·친밀. 한·영.
- **Blue Lips** — 미니멀 팝+R&B(Frank Ocean 비교). 따뜻한 키보드+저음 보컬. 야망 추구의 취약성. **유일한 순수 영어**. 유일하게 polished.

## 4. CORTIS 사운드 DNA

**프로덕션**
- 드럼: 붐뱁(WYW) / 트랩(GO!·FaSHioN·TNT) / 일렉트로닉 루프(REDRED) — 항상 드럼 전면
- 시그니처 레트로 레이어 매 앨범 교체: 60s 사이키 기타(EP1) → 2000s 일렉트로클래시(EP2)
- 악기 밀도 의도적 sparse — 보컬 숨쉬게
- 거칠고 금속적·의도적 unpolished 텍스처
- 짧은 트랙(2~3분), 리플레이 친화
- BPM: 빠른 오프너 → 미드 → 슬로우 클로저 반복

**가사·주제**
- 야망 선언(GO!·WYW) / 정체성 저항(REDRED) / 일상 자전성(ACAI·YCC) / 여정·피로(JoyRide·Wassup·Blue Lips) / 철학적 클로저(Lullaby·Blue Lips) / 크루 연대(YCC)

**언어**: 항상 한·영 코드스위칭. hook·chant는 영어 우세. 순수 한국어 곡 없음. EP2가 EP1보다 한국어 비율↑.

**작법**: 직접 화법(2인칭·1인칭 직구) / chant-driven hook / 내부 레퍼런스(농담·실화·지명) / 이분법 대비(빨강·초록, 소음·침묵) / EP 3막 아치(폭발 오프너→전환→성찰 클로저)

## 5. 오리지널 제작 체크리스트 ("CORTIS답게")

**프로덕션**: ☐ 붐뱁/트랩 드럼 전면 ☐ 레트로 레이어 1개(60s기타/2000s전자/재즈) ☐ 낮은 악기밀도 ☐ unpolished 텍스처 ☐ 2~3분 압축

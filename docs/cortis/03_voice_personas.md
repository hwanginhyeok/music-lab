# CORTIS 5인 Voice Persona 카드 (제작용 SSOT)

> 형님 지시 핵심: "페르소나는 멤버별 5명, 목소리를 정교하게 특징화."
> 이 카드를 곡 제작 시 **파트별 보컬 묘사(Suno 영문 태그)** + **가사 파트 배분**에 직접 사용.
> Suno는 5인 개별 음성을 못 지정하므로 → 섹션별 보컬 캐릭터 묘사로 크루 질감 재현.

---

## 🎙 Voice Persona ×5

### Martin 🔴 — "선언하는 설계자"
- **음색(timbre)**: thick, confident, warm mid-low male
- **딜리버리**: sing-rap, punchy, beat-locked, melodic-rap (Tyler/Mac Miller 결)
- **언어**: EN/KR 자연 전환
- **역할**: 오프닝 선언 / verse2 에너지 증폭
- **Suno 묘사**: `confident thick mid-low male sing-rap, punchy bilingual flow, swagger`

### James 🟢 — "다국어 정밀 전사"
- **음색**: cool, restrained, crisp mid male
- **딜리버리**: precise rap, clean articulation, 코드스위칭(영·한·중/태 단어 삽입)
- **역할**: verse1 정밀 플로우 (차갑게 시작)
- **Suno 묘사**: `cool precise mid male rap, crisp articulation, multilingual code-switch`

### Juhoon 🔵 — "감정 앵커"
- **음색**: clear, emotive, tender mid male
- **딜리버리**: heartfelt 보컬, 멜로디 연결, 감정 전달 우선
- **역할**: pre-chorus 감정 빌드 / bridge 감정 최고점
- **Suno 묘사**: `emotive clear tender mid male vocal, heartfelt, expressive`

### Seonghyeon ⚫ — "훅을 쓰고 훅을 사는 조용한 폭탄"
- **음색**: soft-spoken with sharp dynamic edge (섬세→폭발)
- **딜리버리**: 중독적 탑라인 훅, 보컬-래퍼 하이브리드, R&B·재즈 감각
- **역할**: **메인 훅/코러스** (CORTIS 사운드 아이덴티티) + 아웃트로 애드립
- **Suno 묘사**: `soft yet dynamic main male vocal, ultra-catchy melodic hook, builds to powerful belt`

### Keonho 🟡 — "이름을 박는 배짱의 막내 감독"
- **음색**: magnetic, self-assured young male
- **딜리버리**: 카리스마 랩-보컬(음정보다 전달력), 셀프 네임드롭·스웩
- **역할**: rap break 스웩/네임드롭
- **Suno 묘사**: `magnetic self-assured young male rap-vocal, swagger, name-drop bravado`

## 🧩 표준 파트 배분 템플릿 (CORTIS 결)
```
[Intro/랩 선언]      Martin
[Verse 1/정밀 플로우] James
[Pre-Chorus/감정]    Juhoon
[Chorus/중독 훅]     Seonghyeon (+전원 배킹)
[Verse 2/에너지업]   Martin
[Post-Chorus 챈트]   전원 (콜앤리스폰스)
[Bridge/감정 최고점] Juhoon + Seonghyeon
[Rap Break/스웩]     Keonho(네임드롭) → James
[Final Chorus]      Seonghyeon lead + 전원 유니즌
[Outro 애드립]       Seonghyeon + Juhoon
```

## 🎚 곡 전체 Suno 스타일 베이스 (사운드 DNA)
`Korean hip-hop boy group, boom-bap OR trap drums up front, sparse instrumentation, one retro signature layer (60s psych guitar / 2000s electroclash synth / jazz seq), gritty intentionally-unpolished texture, chant-driven hook, Korean-English code-switching, 2-3 min, replay-friendly`

> 곡마다 레트로 레이어 1개를 골라 변주 (앨범 내 곡별 차별화).
